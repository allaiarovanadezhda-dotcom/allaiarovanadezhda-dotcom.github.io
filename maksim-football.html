📋 Tactics board · Правила

should + глагол = тебе следует
You should drink water. — Тебе следует пить воду.

shouldn't (should not) + глагол = не следует
You shouldn't be late. — Тебе не следует опаздывать.
❗ Без to: should train, should to train

Past Simple ➕ play → played, score → scored
Неправильные: go → went, win → won, run → ran, see → saw

Past Simple ➖ I didn't play. (после didn't — обычная форма!)
❓ Did you play? — Yes, I did. / No, I didn't.
