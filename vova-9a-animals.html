Частые ошибки

✗

✗
would + V1 (2nd) или would have + V3 (3rd). would had не бываетI would had swim → I would swimI would have swum (3rd)
✓
If I were / If I was — оба варианта ок. can → couldIf I could have any pet, I'd get a wolf.
✓
