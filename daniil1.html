past_simple.md

> Past Simple — что это?

Это прошедшее время: что было вчера, на прошлой неделе, давно.

1. Правильные глаголы → + ed

play  → played    // [плэйд]
watch → watched   // [уочт]
want  → wanted    // [уонтид]

2. Неправильные глаголы → 2-я форма

Их надо просто выучить — они во вкладке «слова».

go  → went     // ❌ goed
eat → ate      // ❌ eated
see → saw      // ❌ seed

🙀 Кот, когда ты написал «goed»

3. Глагол be → was / were

I / he / she / itwasI was at home.
you / we / theywereWe were at sambo.
negative_and_question.js

> Отрицание и вопрос

Помогает слово did. Оно уже показывает прошлое, поэтому глагол — обычный (1-я форма)!

// ✅ утверждение
I went to school.

// ❌ отрицание: didn't + 1-я форма
I didn't go to school.     // не didn't went!

// ❓ вопрос: Did + кто + 1-я форма
Did you go to school?
— Yes, I did. / No, I didn't.

// Запомни: did + went = 🐞 баг. did + go = ✅
